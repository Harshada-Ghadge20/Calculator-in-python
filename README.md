# Calculator-in-python
Python Calculator Application

A simple command-line based calculator application developed using Python. This project performs basic arithmetic operations such as addition, subtraction, multiplication, and division with proper user input validation and exception handling.

Features

* Addition, Subtraction, Multiplication, and Division
* Menu-driven interface
* Continuous operation using loops
* Exception handling for invalid inputs
* Division-by-zero handling
* Beginner-friendly and easy-to-understand code structure

Technologies Used

* Python 3

Concepts Used

* Functions
* Conditional Statements
* Loops 
* Exception Handling
* User Input Handling
